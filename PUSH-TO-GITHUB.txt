PUSH TO GITHUB INSTRUCTIONS
============================

Open cmd.exe (NOT PowerShell - PowerShell has path issues on Windows)

Then run these commands:

cd /d C:\Dev\Projects\Cleaners

REM Add your GitHub remote (replace YOUR_USERNAME with your actual username)
git remote add origin https://github.com/YOUR_USERNAME/sparkles-from-dust.git

REM Push to main branch
git branch -M main
git push -u origin main --force-with-lease

============================================

After pushing, enable GitHub Pages:
1. Go to https://github.com/YOUR_USERNAME/sparkles-from-dust/settings/pages
2. Source: Deploy from a branch
3. Branch: main / MAIN
4. Save

Your site will be at: https://YOUR_USERNAME.github.io/sparkles-from-dust
